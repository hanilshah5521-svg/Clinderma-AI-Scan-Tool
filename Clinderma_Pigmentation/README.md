# Clinderma Pigmentation

Canonical project directory for the Clinderma pigmentation segmentation pipeline.

Folders:
- src/                  Python source code
- data/raw/             Raw datasets or temporary dataset references
- data/normalized/      Common normalized dataset representation
- data/splits/          Frozen train/validation/test splits
- experiments/          Experiment definitions
- runs/                 Training runs and checkpoints
- reports/              QC, metrics and rankings
- exports/              Final model artifacts
- config/               Configuration files
- scripts/              Colab/setup/utility scripts

Do not place datasets or model checkpoints here manually unless the pipeline instructs you to.
